# Player Chat

统一前端（React + Vite + Ant Design）：玩家对话 / 测试账号 / 工单，以及客服工作台。

```bash
npm install
npm run dev   # http://localhost:5173
```

| 路径 | 说明 |
|------|------|
| `/` | 玩家聊天 |
| `/accounts` | 测试账号 |
| `/tickets` | 我的工单 |
| `/admin` | 客服工作台 |

生产构建：`npm run build`。Docker 部署见仓库根目录 `docker-compose.yml`（`http://localhost:5175`）。
